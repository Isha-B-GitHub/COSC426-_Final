# COSC426 Final Project - Learning from Participation: A Machine Learning Approach to Student Performance

**Description**
In my project, I am analyzing a dataset that took data from the learning management system (LMS) Kalboard 360. I am looking at the participation features in the dataset to see if we can accurately predict the academic class of a student based on participation characteristics. I also want to find out what the most important features are.

**Installation Instructions**
Install Python 3.1. Run the cells in sequential order. Ensure that the kernel you choose to run the code says: base (Python 3.11.5).

**Use**
Use the project by clicking the "Run" button next to each cell. Make sure to run each cell sequentially.
